Why mathra

    
One small library, the same output everywhere: JavaScript, Python, Rust and the terminal.

    

      

        

        
It speaks the equation

        
The SVG's <title> carries the phrase a screen reader says: “1 over 2”, not “image”.

      

      

        
pt-BR

        
It speaks 16 languages

        
From Português to 日本語. The language changes how numbers are read and written (in pt-BR, 3,14 is one number and \sin is sen) and the language of the speech.

      

      

        

        
It forgives broken input

        
Typos and editor leftovers are fixed and reported as numbered warnings. Strict refuses them, like TeX.

      

      

        

        
It reads LaTeX, MathML and AsciiMath

        
MathML pasted from Word or Google Docs, AsciiMath like sum_(i=1)^n i^2: the same tree of meaning, the same drawing and speech. See the reference.

      

      

        
CMU

        
It writes braille

        
Every equation also comes out in braille: the CMU for Portuguese and Spanish, Nemeth for the other languages, following their official documents and compared with MathCAT. How far to trust it.

      

      

        

        
It draws chemistry

        
chemfig structures, reaction schemes and mechanism arrows, inside any equation. A screen reader hears “structure of C7 H8, with 1 aromatic ring”: the formula is counted from the drawing.

      

      

        

        
It draws diagrams

        
Commutative diagrams in amscd, tikz-cd or xymatrix: arrows in any direction, bent, dashed or hooked, read aloud one arrow at a time.

      

      

        
17.9 µs

        
It is fast and stable

        
Mean time per equation on the corpus. The same input always writes the same bytes.

Reading the numbers

      
    
        
  • KaTeX is faster and lighter to ship. It writes HTML that depends on its stylesheet and web fonts, so its output is not a standalone image: it cannot go into an email, a README, a slide or a PDF as is. That is why its output looks smallest.
    • 
        
  • MathJax's SVG output is the closest equivalent to mathra's: one standalone SVG per equation. Here mathra is about 4× faster, with output of similar size.
    • 
        
  • Almost half of mathra's download is its font: 356 of the 782 KB are STIX Two Math, embedded so the output never depends on what is installed, and cut down to the glyphs mathra draws; the 16 languages add 35 KB and structural chemistry about 50 KB. Noto Emoji, which the terminal and Python embed, is not part of it: the playground downloads it (756 KB) only for an equation with a character the math font lacks, such as an emoji. Outside the browser (CLI, Rust, Python) nothing is downloaded at all, and a native conversion takes 17.9 µs on average.
    • 
        
  • The corpus favors mathra: its 116 constructions were written while building it, and include pt-BR and mathra-only commands. The playground's 18 examples are standard LaTeX except three that only mathra reads (\SI, \sen, \divchave).
    • 
        
  • “Converted cleanly” means no error and no command drawn in red. MathJax runs with all its TeX packages except noundefined; KaTeX with throwOnError and mhchem.
    • 
        
  • Snapshot: Node 24, Apple M5, 50 conversions per equation after a warm-up; times, counts and sizes from one run of the current code. The script is in bench/: cd bench && npm install && npm run compare.
    • 
      

    

  


  

    
Use it

    
Pick your platform. All four packages run the same core, so an equation gives the same SVG, byte for byte, wherever it is converted.

    

      

        
JavaScript and TypeScript
on npm

        
Node, bundlers (Vite, webpack, esbuild) and browsers. Types included.

        npm install @mathlabs/mathra

import { init, texToSvg, render } from "@mathlabs/mathra";

await init();  // browsers and bundlers; Node needs nothing
const svg = texToSvg("3,14", { locale: "pt-BR" });
const { speech, braille, warnings } = render("x^2");
render("sqrt(x)/2", { input: "asciimath" });  // or "mathml"

      

      

        
Python
on PyPI

        
Python 3.9 and later, wheels for Linux, macOS and Windows. Types included.

        pip install mathra

import mathra

svg = mathra.tex_to_svg(r"\sin x = 0.5")
r = mathra.render(r"\frac{3}{4}", locale="fr")
r["speech"]   # 'trois quarts'
mathra.render("x^2", locale="pt-BR")["braille"]  # '⠭⠡⠼⠃'

      

      

        
Terminal
on crates.io

        
One binary, SVG to stdout or files; --batch for many at once.

        cargo install mathra-cli

mathra 'x \le 2.75' -o inequality.svg
mathra '3,14 + \sin x' --locale pt-BR
mathra 'x = -1' --speech
mathra '\vert A\vert = C_{16,2' --explain
mathra 'sum_(i=1)^n i' --from asciimath
mathra '\frac{3}{4}' -l pt-BR --braille

      

      

        
Rust
on crates.io

        
The core itself, for servers and native apps. API docs on docs.rs.

        cargo add mathra

let r = mathra::convert("3.14", &mathra::Options::default())?;
println!("{}", r.svg);
println!("{}", r.speech);
